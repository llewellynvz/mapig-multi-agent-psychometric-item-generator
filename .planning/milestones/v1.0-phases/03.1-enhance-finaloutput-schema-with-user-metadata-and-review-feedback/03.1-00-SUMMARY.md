## Technical Implementation

### Test Design Patterns

**1. Optional Fields with Backward Compatibility:**
- New fields (user_request, linguistic_feedback, bias_feedback, content_feedback) must be optional
- Existing code creating FinalOutput without new fields must continue working
- Default values: user_request=None, feedback arrays=[] (empty lists)

**2. Mutable Default Prevention:**
- Explicit test for Pydantic Field(default_factory=list) pattern
- Verifies feedback array instances are not shared across FinalOutput objects
- Prevents classic Python mutable default bug

**3. GraphState Integration:**
- Test verifies finalize_node extracts metadata from GraphState
- Maps: state["user_request"] → final_output.user_request
- Maps: state["linguistic_comments"] → final_output.linguistic_feedback
- Maps: state["bias_comments"] → final_output.bias_feedback
- Maps: state["content_comments"] → final_output.content_feedback

### Test Data Structure

All tests use complete, valid mock data:
- UserRequest with all required fields
- ReviewComment instances for each review type (linguistic, bias, content)
- DraftItem with rationale and evidence citations
- AuditMetadata with validation attempt tracking
- EvidenceChunk with source_id for citation tracking
- ItemValidation with dimension scores for validation result enrichment
