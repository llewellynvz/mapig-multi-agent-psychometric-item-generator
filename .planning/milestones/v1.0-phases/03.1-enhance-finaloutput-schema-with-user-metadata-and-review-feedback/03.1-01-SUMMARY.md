```python
class FinalOutput(BaseModel):
    """Final items plus audit metadata.

    Phase 03.1 enhancement: Added user_request and review feedback fields
    to enable complete metadata export without breaking existing consumers.

    # Phase 03.1: Optional metadata for complete context export

        default=None,
        description="Original user request with construct definition, target population, and constraints."
    )

    linguistic_feedback: List[ReviewComment] = Field(
        default_factory=list,
        description="All linguistic reviewer comments across iterations."
    )

    bias_feedback: List[ReviewComment] = Field(
        default_factory=list,
        description="All bias reviewer comments across iterations."
    )

    content_feedback: List[ReviewComment] = Field(
        default_factory=list,
        description="All content reviewer comments across iterations."
    )
```

**Key Implementation Details:**
- Used `Field(default=None)` for optional object (user_request) - prevents Pydantic validation issues
- Used `Field(default_factory=list)` for arrays - prevents mutable default instance sharing bug
- All fields optional - maintains backward compatibility with existing API consumers

## Key Decisions

1. **Field(default=None) for optional objects:** Used `Field(default=None)` instead of bare `None` for `user_request` to ensure Pydantic validation works correctly.

2. **Field(default_factory=list) for arrays:** Used `default_factory=list` instead of `default=[]` to prevent mutable default instance sharing (critical bug prevention).

3. **state.get() with defaults:** Used `state.get("field", [])` pattern for graceful handling when GraphState fields are missing.

4. **Field name mapping:** GraphState uses "linguistic_comments" but FinalOutput uses "linguistic_feedback" for semantic clarity (feedback vs internal comments).
