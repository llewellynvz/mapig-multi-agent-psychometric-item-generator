## Validation Logic from Research

Per RESEARCH.md Pattern 1 "Validation Node with Chain-of-Thought Scoring":
- 4 dimensions: correspondence (50%), distinctiveness (25%), clarity (15%), specificity (10%)
- Chain-of-thought reasoning BEFORE numeric score
- 1-10 categorical scale with rubric anchors
- Weighted score computation: sum(dimension * weight)
- Accept threshold: weighted_score >= 7.0

Per RESEARCH.md Pattern 5 "Weighted Multi-Dimensional Rubric":
- Define clear 1-10 scale anchors per dimension
- Use implicit weighting (LLM applies weights mentally, not arithmetic)
- Include construct definition and item text in validation context

## Rubric Structure from Research

Each dimension needs:
- Definition (what it measures)
- Scale anchors (10, 9, 7-8, 5-6, 3-4, 1-2 with concrete descriptions)
- Examples of high vs low scores (optional but helpful)

   - Definition: Is the item clearly about THIS construct rather than nearby constructs?
   - Scale anchors (10: uniquely measures target, 1-2: measures different construct)

5. **Dimension 3: Clarity (Weight: 15%)**
   - Definition: Is the item unambiguous, concise, and comprehensible to target population?
   - Scale anchors (10: perfectly clear, 1-2: incomprehensible or multiple interpretations)

   ```
   Weighted_Score = (Correspondence * 0.5) + (Distinctiveness * 0.25) + (Clarity * 0.15) + (Specificity * 0.10)
   ```

   - Evaluate each item independently (avoid position bias)
   - Chain-of-thought reasoning is required before scoring
