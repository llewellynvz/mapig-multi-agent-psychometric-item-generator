       - Build 2D heatmap data from flat cells list (find cell by indices, symmetric lookup, diagonal = 1.0)

       - Cell size responsive: `Math.min(40, availableWidth / numItems)` — scales down for large item sets
       - Axis labels along top and left: "Item 1", "Item 2", ... (rotated 45deg for top)
       - Color legend bar below heatmap showing gradient from -1 to +1
       - Each cell: onMouseEnter triggers onCellHover, onClick triggers onCellClick
       - Dark mode support: stroke color uses CSS variable --border
       - Follow research pattern from 08-RESEARCH.md Pattern 3

    4. **Create src/components/CorrelationTooltip.tsx:**
       - Hover tooltip component showing:
         - "Item {i+1} x Item {j+1}"
         - "r = {correlation}" (bold, 3 decimal places)
         - "95% CI: [{ci_low}, {ci_high}]"
         - Truncated item texts for both items (30 chars)
       - Use @visx/tooltip's useTooltip hook or simple div positioned near cursor
       - Style: dark bg (#0b2a34), light text, rounded corners, shadow

    5. **Create src/components/CorrelationSummaryCard.tsx:**
       - Props: `{ matrix: CorrelationMatrix }`
       - Uses SurfaceCard, CardHeader, CardTitle, CardContent (existing components)

         - **McDonald's Omega (omega):** Value formatted to 3 decimal places + Pill showing "Pass" (green) if >= 0.70 or "Warning" (amber) if < 0.70
           - Educational text: "Measures how well items consistently measure the same construct"
         - **Mean Inter-Item Correlation:** Value formatted to 3 decimal places + flag status
           - Pill: "Optimal" (green) for 0.15-0.50, "Low" (amber) for < 0.15, "High" (amber) for > 0.50
           - Educational text: "Average correlation between all item pairs; 0.15-0.50 is optimal for broad constructs"
         - **Internal Consistency Assessment:** One-line summary based on flag

       - Disclaimer text at bottom: "LLM-estimated, not empirically validated" in muted-foreground (CORR-05)
       - Warnings are informational only — no blocking action, no revision suggestions (per user decision)

           - "Export JSON" triggers download of full CorrelationMatrix JSON

         - Correlation value + CI
         - "Reasoning" field (if available in cell data — note: CorrelationCell schema may need reasoning field added)
