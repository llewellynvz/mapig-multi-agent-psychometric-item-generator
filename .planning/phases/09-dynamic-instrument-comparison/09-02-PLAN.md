    1. **Pydantic response schemas (internal to module):**
       ```python
       class ConvergentValidityScore(BaseModel):
           score: float  # 0.0-1.0
           reasoning: str

       class DiscriminantValidityScore(BaseModel):
           estimated_correlation: float  # -1.0 to 1.0
           reasoning: str
       ```

    2. **`score_convergent_validity(generated_items: list[str], instrument_name: str, instrument_construct: str, target_construct: str) -> float`**
       - Implements dual-direction scoring per user decision (XCON-02): A to B and B to A averaged
       - Forward direction: "How well do these generated items align with {instrument_name} measuring {instrument_construct}?"
       - Reverse direction: "How well does {instrument_name} measuring {instrument_construct} align with these generated items?"
       - Use GPT-5.2 via get_gpt52_analytics_model() with structured output (ConvergentValidityScore)
       - Average the two scores: `(forward.score + reverse.score) / 2.0`
       - Show only averaged result to users per user decision (individual directions are implementation detail)
       - On LLM error, return 0.5 (neutral default) and log warning
       - System prompt: psychometric expert assessing convergent validity on 0-1 scale

    3. **`score_discriminant_validity(generated_items: list[str], instrument_name: str, instrument_construct: str, target_construct: str) -> ConstructPairAnalysis`**
       - Also uses dual-direction scoring (same pattern as convergent) per XCON-02
       - Forward: "Estimate correlation between {target_construct} and {instrument_construct}"
       - Reverse: "Estimate correlation between {instrument_construct} and {target_construct}"
       - Average the two estimated_correlations
       - Set discriminant_validity_flag based on averaged correlation (XCON-03):
         - abs(correlation) > 0.85: "concern" (high overlap warning)
         - abs(correlation) <= 0.85: "adequate"
       - Return ConstructPairAnalysis with construct_a=target_construct, construct_b=instrument_construct
       - On LLM error, return ConstructPairAnalysis with estimated_correlation=0.3, flag="adequate", reasoning="Scoring unavailable"

    4. **`_score_single_direction_convergent(generated_items, instrument_name, instrument_construct, target_construct, direction: str) -> ConvergentValidityScore`**
       - Internal helper: builds prompt, calls GPT-5.2, parses response
       - Follow item_comparison.py pattern for prompt structure

    5. **`_score_single_direction_discriminant(target_construct, comparison_construct, direction: str) -> DiscriminantValidityScore`**
       - Internal helper for discriminant scoring
       - Prompt asks LLM to estimate expected correlation between two constructs based on psychological literature
