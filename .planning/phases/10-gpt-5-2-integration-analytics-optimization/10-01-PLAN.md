   **IMPORTANT:** The Command/Send approach requires understanding how LangGraph merges parallel results. Each analytics node returns `{"final_output": updated_output}`. With TypedDict(total=False), the last write wins for non-additive fields. Since each analytics node writes to different sub-fields of final_output (correlation_matrix, comparison_instruments, cross_construct_analysis), they will NOT conflict -- but they each deep-copy and return the full final_output. The collect node receives state with all three updates merged by LangGraph.

   **ALTERNATIVE APPROACH (SAFER):** If Send API state merging for `final_output` is problematic (multiple nodes writing to same FinalOutput field causing one to overwrite another's changes), use a single `analytics_dispatch_node` with asyncio.gather instead:
   ```python
   import asyncio

   async def analytics_dispatch_node(state: GraphState) -> GraphState:
       """Run analytics in parallel using asyncio.gather."""
       final_output = state.get("final_output")
       if not final_output or len(final_output.final_items) < 3:
           return {}

       results = await asyncio.gather(
           _run_correlation_async(state),
           _run_comparison_async(state),
           _run_cross_construct_async(state),
           return_exceptions=True,
       )

       updated = final_output.model_copy(deep=True)
       for result in results:
           if isinstance(result, Exception):
               logger.error(f"Analytics task failed: {result}")
               continue
           if hasattr(result, 'correlation_matrix') and result.correlation_matrix:
               updated.correlation_matrix = result.correlation_matrix
           if hasattr(result, 'comparison_instruments') and result.comparison_instruments:
               updated.comparison_instruments = result.comparison_instruments
           if hasattr(result, 'cross_construct_analysis') and result.cross_construct_analysis:
               updated.cross_construct_analysis = result.cross_construct_analysis
           if hasattr(result, 'plagiarism_flags') and result.plagiarism_flags:
               updated.plagiarism_flags = result.plagiarism_flags
           if hasattr(result, 'convergent_validity_score') and result.convergent_validity_score is not None:
               updated.convergent_validity_score = result.convergent_validity_score

       return {"final_output": updated}
   ```
   **Try Send API first.** Fall back to asyncio.gather only if testing reveals merge issues.

4. **Add `collect_analytics_node`** after cross_construct_node (around line ~972):
   ```python
   def collect_analytics_node(state: GraphState) -> GraphState:
       """Collect parallel analytics results and enforce budget cap.

       All analytics updates already applied to state by LangGraph after parallel superstep.
       This node checks budget and adds warning if exceeded.
       """
       with step("collect_analytics_node", state):
           gpt52_enabled = state.get("gpt52_analytics_enabled", False)
           if not gpt52_enabled:
               return {}

           # Calculate GPT-5.2 cost from accumulated tokens
           gpt52_reasoning = state.get("gpt52_reasoning_tokens", 0)
           gpt52_output = state.get("gpt52_output_tokens", 0)
           gpt52_cost = (gpt52_reasoning + gpt52_output) / 1_000_000 * 14.0

           # Check against budget cap
           if gpt52_cost > settings.ANALYTICS_BUDGET_CAP:
               logger.warning(
                   f"ANALYTICS_BUDGET_EXCEEDED cost=${gpt52_cost:.4f} cap=${settings.ANALYTICS_BUDGET_CAP:.2f}"
               )

           return {}
   ```
