## Description

```
I built MAPIG — the Multi-Agent Psychometric Item Generator — an open platform where 11 specialized AI agents collaborate to draft, review, revise, and validate psychometric scale items with full evidence grounding and audit trails.

In this video I walk through the entire pipeline:
- Evidence retrieval from peer-reviewed literature (Perplexity academic search)
- AI-powered item writing grounded in psychometric best practice
- 4-dimension validation gate (correspondence, distinctiveness, clarity, specificity)
- Triple parallel review: linguistic quality, 7-type bias detection, and content validity
- Adaptive revision loops with escalating acceptance thresholds
- Embedding-based inter-item correlation matrix (Hommel & Arslan, 2024 methodology)
- Automated convergent & discriminant validity estimation against published instruments
- Plagiarism detection via sentence-transformer similarity

The system uses Claude Sonnet 4.5, Claude Opus 4.6, GPT-4o, GPT-4o-mini, and GPT-5.2 — each allocated to the agent where it performs best. 90% of quality control decisions use zero tokens via rule-based optimization.

Built with: LangGraph, FastAPI, Next.js, OpenAI Embeddings, Perplexity API
```
